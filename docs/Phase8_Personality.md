# Phase 8: 性格システム(CreaturePersonality)

## 目的

同じ AI でも、猫ごとに「行動の傾向」を変えられるようにする。
学習・記憶は持たず、**既存システムの係数を性格で変化させる**だけの最小実装。

## 追加したクラス

| クラス | 責務 |
|---|---|
| `CreaturePersonality` | 4つの性格値(0〜1)を保持し、各層に「倍率」を提供する**純データ層**。判断はしない。Brain/Needs/Threat/Movement が必要な倍率だけを問い合わせる |

### 4つの性格
| 性格 | 影響する所 |
|---|---|
| 臆病さ(timidity) | 危険検知の反応距離(遠くから逃げる)・逃走速度 |
| 好奇心(curiosity) | 徘徊の広さ(探索範囲)・休憩の短さ |
| 活発さ(activeness) | 移動速度・欲求の増減(早く空腹/早く回復) |
| のんびりさ(relaxedness) | 徘徊の休憩時間・行動を始める溜まり具合(しきい値) |

## 各層がどの倍率を使うか(責務分離は維持)

性格は「倍率を提供するだけ」。使い方は各層が決める:

| 層 | 使う倍率 | 効果 |
|---|---|---|
| ThreatEvaluator | `GetThreatDistanceMult()` | 反応距離 = threatDistance × 倍率 |
| MovementController | `GetMoveSpeedMult()` / `GetFleeSpeedMult()` / `GetWanderRadiusMult()` / `GetWanderPauseMult()` | 速度・逃走速度・徘徊範囲・休憩時間 |
| NeedsController | `GetNeedsRateMult()` | 欲求の増加速度 |
| ActionRunner | `GetNeedsRateMult()` | 行動中の回復速度 |
| CreatureBrain | `GetThresholdMult()` | 行動開始しきい値 |

各層は起動時に `GetComponent<CreaturePersonality>()` で参照を取り、無ければ倍率1.0
(性格なし=従来どおり)として動く。→ 既存アーキテクチャ・判断ロジックは不変。

## Unity での設定方法

- **個別に**: Cat の `Creature Personality` コンポーネントの4つのスライダー(0〜1)を動かす。
  各スライダーに日本語の説明(ツールチップ)あり。
- **まとめて(プリセット)**: メニュー **`CreatureAI > 性格`**
  - 平均 / 臆病な猫 / 元気な猫 / のんびり猫 / 好奇心旺盛な猫
  - シーン内の全猫に適用。再生中は即反映。
- 複数の猫に別々の性格を付けたい場合は、猫ごとに Inspector で調整すればよい。

## 実機でのテスト方法

1. zip 上書き → コンパイル待ち。
2. `CreatureAI > 1. Program Asset を作成`(新規 CreaturePersonality を生成)。
3. 旧 Cat を削除 → `CreatureAI > 2. テスト用の猫を作成`。
   (複数匹置いて比べるなら、Cat を複製するか、もう一度作って位置をずらす)
4. ▶ Play しながら性格プリセットを切り替えて違いを見る:
   - **臆病な猫**: プレイヤーがまだ遠いのに早く逃げ出す。
   - **元気な猫**: 動きが速く、すぐ空腹になり、活発に動く。
   - **のんびり猫**: なかなか動かず、徘徊の休憩が長い。
   - **好奇心旺盛な猫**: 広い範囲をよく歩き回る。
5. Scene ラベルに `性格: 臆0.9 好0.2 活0.4 呑0.5` のように現在値が出る。

## Phase 8 の成功条件

- 性格値を変えると、**同じ AI でも行動傾向が目に見えて変わる**
  (逃げ出す距離・移動速度・空腹の早さ・徘徊の広さ・休憩の長さ)。
- 性格は `CreaturePersonality` に閉じており、各層は**倍率を問い合わせるだけ**
  (判断ロジックは Brain/Threat/Movement のまま=責務分離維持)。
- 性格が無くても従来どおり動く(倍率1.0)。

## 将来の発展(この土台の上で)

- **Memory(記憶)**: 「この場所は怖かった」等を覚え、性格倍率にさらに係数を掛ける。
  消費側(各層)は変更不要。
- **Utility AI**: Brain の `ScoreOf()` に性格の重み付けを足して、性格で「何を優先するか」
  まで変える(今は係数のみ、将来は優先度そのものへ)。
- **個体の見た目**: 性格に応じて色・大きさ・アニメの癖を変える(CreatureAnimator と連携)。
