# Phase 9 — 障害物回避の移動強化(CreatureLocomotion)

実ワールドで壁や家具を**自然に避けながら**目的地へ向かえるようにする軽量な
障害物回避システム。複雑な経路探索(NavMesh / A*)は使わず、Raycast による
ローカルステアリングで「壁を貫通しない・自然に回避する・空けば目的地へ戻る」を実現する。

## 追加したクラス

| クラス | 役割 |
|---|---|
| **`CreatureLocomotion`** | 移動の障害物回避ステアリングを集約。「行きたい方向」を受け取り、Raycast で前方を確認し、塞がれていれば左右に振って通れる方向を選んで「実際に進む変位」を返す純ステアリング。目的地決定・徘徊・逃走の判断は持たない。 |

## 変更したクラス

| クラス | 変更内容 |
|---|---|
| `MovementController` | 3つの移動地点(目的地へ移動 / 徘徊 / 逃走)で、直進の代わりに `CreatureLocomotion.ComputeMove()` を通して回避済みの変位で動くようにした。`CreatureLocomotion` が無ければ従来どおり直進(null 安全)。徘徊先が塞がれたら諦めて別地点を選び直す処理を追加。向きは「実際に進んだ方向」へ回頭(回避で曲がれば自然にそちらを向く)。 |
| `CreatureAISetup`(Editor) | Cat に `CreatureLocomotion` を同梱。テスト用メニュー「4. テスト用の壁を作成」を追加。 |
| `CreatureAIGizmos`(Editor) | Scene ビューに回避の探査方向を可視化(望んだ方向=灰、選んだ方向=緑/塞がれ=赤)。 |

**Brain / Needs / Threat / ActionRunner / TargetSelector は無改造。** 回避は移動層だけで完結する。

## アルゴリズムの概要(ウィスカー・ステアリング + にじり寄り)

1. **正面へ1本 Raycast** して障害物までの**距離**を測る。十分空いていればそのまま前進。
2. ふさがれていたら、**左右へ角度を段階的に広げながら Raycast**(±(maxAvoidAngle/probeSteps)
   …±maxAvoidAngle)。最初に「十分空いた」側へ向く(＝壁に沿って回り込む)。
3. **一度避け始めた側を短時間(turnCommitTime)優先**して、左右にガタガタ振動するのを防ぐ
   (自然な壁沿い歩行)。両側が同時に空いたときは個体差のため最初だけランダムに左右を選ぶ。
4. どの方向も十分には空いていない(家具の多い室内など)場合は、**最も遠くまで空いている方向へ
   「障害物の clearance 手前まで」進む(にじり寄り)**。clearance 以内まで全方向ふさがれている
   ときだけ停止する(壁を貫通しない)。

家具のある室内で固まらないための要点が2つある:
- **距離ベースの判定**: 「probeDistance 先まで空いていないと進まない」ではなく「空いている分だけ
  進む」。室内では常にどこかの家具が近くにあるため、二値判定だと全方向ふさがり扱いで完全停止する。
- **lookAhead(目的地までの残り距離)より先の障害物は無視**: これが無いと「壁際に置いた餌皿」に
  近づく途中で壁が検知され、永遠に到達できない。

また、**トリガーコライダー**(ドア・ギミックの反応領域。家プレハブに多い)と**自分自身の体**
(差し替えモデルのコライダー)は障害物として扱わない。

「行きたい方向(目的地/徘徊/逃走)」を入力、回避を補正とする構造なので、
**障害物が無ければ従来どおり最短で進み、塞がれている間だけ迂回し、空けば目的地へ復帰**する
(目的地追従と回避が両立)。1フレームの Raycast は「空いていれば1本、塞がれていても
最大 1+2×probeSteps 本」で、VRChat/UdonSharp でも十分軽量。

## Inspector で調整できるパラメータ(CreatureLocomotion)

| パラメータ | 意味 | 既定 |
|---|---|---|
| `avoidObstacles` | 回避の ON/OFF。OFF で従来の直進に戻る | true |
| `obstacleMask` | 障害物とみなすレイヤー。**空(Nothing)なら全レイヤー**。実ワールドでは壁・家具のレイヤーに限定推奨(プレイヤー/Pickup の誤検知防止) | 空=全て |
| `probeDistance` | 前方の先読み距離(m)。長いほど早めに曲がる | 1.5 |
| `clearance` | 障害物へどこまで近づいてよいか(m)。体の半径より少し大きく | 0.25 |
| `rayHeight` | Raycast を出す高さ(足元から m)。体の中心が目安 | 0.3 |
| `maxAvoidAngle` | 左右に振って探す最大角度(度) | 90 |
| `probeSteps` | 左右それぞれ何段階で探すか(多いほど滑らか・Raycast 増) | 3 |
| `turnCommitTime` | 避け始めた側を優先し続ける秒数(振動抑制) | 0.6 |

移動速度そのものは従来どおり `CreatureProfile.moveSpeed` × 性格倍率。

## Unity でのテスト方法

1. `CreatureAI > 1. Program Asset を作成`(新スクリプト `CreatureLocomotion` を登録)。
2. `CreatureAI > 2. テスト用の猫を作成`。
3. `CreatureAI > 4. テスト用の壁を作成`(Cat と FoodBowl の間にコライダー付きの壁が立つ)。
4. ▶ Play。空腹が溜まると猫が FoodBowl へ向かうので、**壁を貫通せず回り込む**か確認する。
5. **Scene ビュー**で猫を見ると、回避の探査線が出る:
   - 灰の線 = 本当に行きたい方向
   - 緑の線 = 実際に進む方向(空いている)
   - 赤の線/赤い球 = 塞がれて停止
6. 頭上 HUD でも `[Moving]` のまま壁沿いに動くのが分かる。
7. 調整: 早く曲がりすぎ/遅すぎるときは Cat の `CreatureLocomotion` で `probeDistance` や
   `maxAvoidAngle` を変える。回避を切って比較したいときは `avoidObstacles` を OFF。

### 成功条件との対応
- 壁へ向かって歩いても貫通しない → 塞がれたら変位ゼロで停止 + 事前に迂回。
- 障害物があれば自然に回避 → 左右探査 + 片側優先で壁沿いに回り込む。
- 障害物がなくなれば再び目的地へ → 正面が空けば即 desiredDir に復帰。
- 既存 CreaturePoint への移動に影響なし → 障害物が無ければ従来と同じ最短移動。
- Brain/ActionRunner 無改造 → 変更は移動層(MovementController / CreatureLocomotion)のみ。

## 既知の制限事項

- **局所回避のみ(経路探索なし)**。目的地が壁で**完全に囲われている**と回り込めず、壁の手前で
  停止する(貫通はしない)。凹んだ袋小路(コの字)にも弱い。実運用では地点を開けた場所に置くか、
  将来 Waypoint/NavMesh を足す。
- **平面(XZ)前提**。段差・階段・空中の障害物は考慮しない(足元付近の水平 Raycast のみ)。
  `rayHeight` より低い障害物(座布団・低い段差など)は検知せず通り抜ける。
- **障害物にはコライダーが必要**。コライダーの無い見た目だけのオブジェクトは検知できない。
  逆に `obstacleMask` を絞らないと、プレイヤーや Pickup を障害物として避けてしまう。
  トリガーコライダーは意図的に無視する(ドア・ギミックの反応領域を塞がないため)。
- **他個体は避けない**(猫同士は素通り)。地点の占有で取り合いは防ぐが、混雑時の相互回避は範囲外。
- `probeDistance` を極端に長く / `probeSteps` を多くすると Raycast が増える。多数配置時は控えめに。

## 将来の発展(設計は維持)

`CreatureLocomotion` は「行きたい方向 → 安全な方向」を返す純ステアリング。上位に
**Waypoint 追従**や **NavMesh 経路**を足す場合は、経路上の次の点への方向を `desiredDir` として
渡すだけでよく、本クラスは無改造のまま局所回避を担い続ける(大域=経路、局所=回避 の二層構造)。
